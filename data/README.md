# Data

The production chatbot uses a Google Sheets programme catalogue rather than committing the live dataset to this repository.

The catalogue contains university/programme information used by the course-matching workflow. A separate leads sheet stores enquiries submitted through the chatbot.

## Why the live sheets are not committed

The repository intentionally excludes:

- live Google Sheet identifiers and URLs;
- personal lead/contact information;
- credentials or API configuration;
- production-only operational data.

A small anonymized sample dataset can be added later if a reproducible demonstration is required.
